# Propuestas de revisión de fuentes sobre _Echinopsis pachanoi_

Fecha de preparación: 2026-09-05. Este documento prepara el trabajo del
revisor en `/admin/review`; no ejecuta decisiones, no modifica estados y no
publica proyecciones.

## Alcance observado

La base local contiene 14 filas `source_records` pendientes del proveedor
`web-page`, que corresponden a 10 `source_record_id` estables. Cuatro IDs
aparecen dos veces por cosechas repetidas: SciELO, UNPRG, UNTumbes y UTN.
Todas las filas carecen actualmente de `record_provenance`, por lo que el diff
contra lo publicado se muestra honestamente como “sin proyección pública
vinculada”. La propuesta se resuelve por el ID estable y se presenta igual para
cada duplicado; no se copian cuerpos HTML, PDF, tablas ni imágenes al corpus.

Las propuestas viven en
`packages/shared/src/source-review-proposals.ts` y se validan con
`pnpm quality:source-review`. Son una ayuda editorial: el operador debe
confirmar licencia, atribución, privacidad, alcance y nota antes de aceptar o
rechazar desde la API protegida.

## Siguiente paso manual

El revisor debe abrir la evidencia enlazada, completar la nota de revisión y
marcar las casillas de la bandeja. Una recomendación `accepted` sólo significa
“aceptar la fuente atribuida con alcance situado”; no publica automáticamente
claims sin una proyección y procedencia válidas. Las recomendaciones `hold` y
`rejected` conservan explícitamente el bloqueo o la ausencia de evidencia.
