# `@wachuma/lineage`

Dominio de ejemplares, culturas biológicas, identificadores públicos, QR y
relaciones de linaje para plantas, hongos, semillas, clones y cepas.

El paquete mantiene la construcción del árbol como función pura. La API y la
base de datos son responsables de filtrar visibilidad antes de entregarle
relaciones; el paquete no conoce coordenadas ni permisos.
