# @wachuma/procgen

Generadores procedurales deterministas y propios de WACHUMA.

Las implementaciones generan distribución de areolas de un cactus paramétrico,
ramificaciones por L-system y puntos de filotaxis. La semilla, la versión del
algoritmo y los parámetros deben guardarse junto con cualquier asset exportado.

Son primitivas geométricas interpretativas: producen segmentos y puntos
reproducibles, no una reconstrucción científica automática de un organismo.

Para cactus columnares, las primitivas se organizan como meristemos, areolas,
costillas y un grafo de tallos con historia, no como un cilindro con adornos.
La especificación de estados, ecuaciones, invariantes y límites está en
[desarrollo, cultivo y animación](../../docs/architecture/developmental-animation.md).
