# `@wachuma/cultivation`

Dominio de manuales de cultivo versionados, afirmaciones técnicas, fuentes y
eventos de cultivo.

La integración entre eventos de cultivo y desarrollo procedural está definida
en [desarrollo, cultivo y animación de cactus columnares](../../docs/architecture/developmental-animation.md).
Los eventos observados se conservan como evidencia; no se convierten por sí
solos en una recomendación ni en una predicción de crecimiento o floración.
