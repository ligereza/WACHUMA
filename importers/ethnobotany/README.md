# Importador etnobotánico

Fuera del primer corte. Requiere revisión individual de las licencias de cada
dataset y validación de procedencia/comunidad antes de cualquier importación.
El contrato `ethnobotany` es `manual_review`, exige comunidad, perspectiva,
territorio, fuente, licencia/restricción y estado `pending`; no se permite
importación automática ni publicación por defecto.
